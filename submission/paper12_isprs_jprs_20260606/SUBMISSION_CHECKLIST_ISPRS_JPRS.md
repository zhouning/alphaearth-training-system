# ISPRS JPRS Submission Checklist

Use this checklist before uploading to the Elsevier submission system.

## Manuscript

- [ ] Confirm formal author list, affiliations, and corresponding author email.
- [ ] Compile `02_latex_source/main_isprs_jprs.tex`.
- [ ] Confirm title matches the intended ISPRS JPRS framing.
- [ ] Confirm abstract length and remove unsupported claims.
- [ ] Confirm all references resolve.
- [ ] Confirm all labels and cross-references resolve.
- [ ] Confirm appendix placement: main manuscript or supplementary material.
- [ ] Review overfull boxes in the LaTeX log.

## Journal Fit

- [ ] Emphasize remote sensing methodology, computer vision, and operational LULC validation.
- [ ] Avoid framing the manuscript as a software-platform paper.
- [ ] Keep the scope centered on Prithvi-100M unless a second backbone is added.
- [ ] Moderate "first benchmark" claims unless the literature search is refreshed.

## Figures and Tables

- [ ] Regenerate all figures from the latest JSON/CSV files.
- [ ] Verify every table value against source result files.
- [ ] Confirm figure filenames and captions are journal neutral.
- [ ] Confirm PDF figures are readable in single-column and preprint layouts.

## Declarations

- [ ] Declaration of competing interest is confirmed.
- [ ] Funding statement is confirmed.
- [ ] Author statement is confirmed.
- [ ] Data availability statement includes public benchmarks and Linhe restrictions.
- [ ] Generative AI disclosure is confirmed.

## Supplementary Material

- [ ] Include result JSON/CSV files.
- [ ] Include figure-generation scripts.
- [ ] Include enough logs or metadata to reproduce reported tables.
- [ ] Remove private paths, tokens, and restricted data locations.
- [ ] Zip supplementary material separately from source files.

## Upload Order

- [ ] Main manuscript PDF.
- [ ] LaTeX source files.
- [ ] Cover letter.
- [ ] Highlights.
- [ ] Declarations.
- [ ] Supplementary material archive.
