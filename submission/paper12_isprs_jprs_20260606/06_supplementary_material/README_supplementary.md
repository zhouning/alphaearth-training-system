# Supplementary Material Package

This directory contains reproducibility artifacts for the Paper 12 ISPRS JPRS submission.

## Contents

- `paper12_results/` - BigEarthNet, LandCover.ai, LoRA ablation, full-finetuning, rank-sensitivity, LoveDA two-direction full-finetuning, EuroSAT channel-bridge, and SatMAE-compatible second-backbone result files.
- `results/` - EuroSAT and GeoAdapter result JSON files copied from the AlphaEarth-System working tree.
- `scripts/` - figure-generation and diagnostic scripts copied from the manuscript source tree.

Note: `paper12_results/eurosat_channel_bridge*.json` is the rerun output after the checkpoint-path fix and can be cited as manuscript evidence once the package is uploaded.

Completed: `paper12_results/peft_capacity_sweep.json` and `paper12_results/peft_capacity_sweep_summary.json` are mirrored from `colab/paper12_peft_capacity_sweep_colab.ipynb` and are manuscript-ready once the package is uploaded.

Completed: `paper12_results/second_backbone_eurosat.json` and `paper12_results/second_backbone_eurosat_summary.json` are mirrored from `colab/paper12_second_backbone_eurosat_colab.ipynb` and support the bounded SatMAE-compatible second-backbone validation.

Completed: `paper12_results/review_audit_summary.json` is a deterministic derived audit generated by `python -m geoadapter.bench.paper12_audit`; it does not add training runs, but records the exact capacity, channel-bridge, second-backbone, LoveDA diagnostic, model-scope, label-source, and decoder-capacity comparisons cited in the revised manuscript.
